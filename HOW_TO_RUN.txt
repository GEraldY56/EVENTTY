📱 CARA MENJALANKAN APLIKASI:

1. MENGGUNAKAN CHROME (WEB) - RECOMMENDED
   Buka terminal dan jalankan:
   
   flutter run -d chrome
   
   Atau:
   
   flutter run -d edge
   
   ✅ Aplikasi akan otomatis membuka di browser Chrome/Edge

2. MENGGUNAKAN WINDOWS DESKTOP (Jika mengalami error symlink)
   
   A. Enable Developer Mode di Windows:
      - Buka Settings (Win + I)
      - Pilih "Privacy & Security" atau "Update & Security"
      - Pilih "For Developers"
      - Aktifkan "Developer Mode"
      - Restart komputer
   
   B. Setelah Developer Mode aktif, jalankan:
      
      flutter run -d windows

3. MENGGUNAKAN ANDROID EMULATOR/DEVICE
   
   A. Pastikan Android Studio terinstall
   B. Buka Android Emulator atau hubungkan device Android
   C. Jalankan:
      
      flutter run -d android
   
   Atau pilih device spesifik:
      
      flutter devices
      flutter run -d <device-id>
