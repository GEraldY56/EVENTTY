⚡ HOT RELOAD/RESTART:
================================================================================

Saat aplikasi berjalan, tekan:

r   - Hot Reload (cepat, maintain state)
R   - Hot Restart (reset state)
d   - Detach (app tetap jalan)
c   - Clear console
q   - Quit (stop app)
h   - Help (list commands)

================================================================================
📱 UNTUK WINDOWS DESKTOP:
================================================================================

Jika muncul error "symlink support":

1. Buka Settings (Win + I)
2. Pilih "Privacy & Security" atau "Update & Security"
3. Pilih "For Developers"
4. Aktifkan "Developer Mode"
5. Restart komputer
6. Jalankan: flutter run -d windows

Atau langsung buka Developer Settings:
start ms-settings:developers
